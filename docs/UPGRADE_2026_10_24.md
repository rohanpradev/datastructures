# October 24, 2026: Bun 1.4.4 and dependency refresh

The runtime and CI now use **Bun 1.4.4**, released October 22, 2026.
`packageManager` selects the same version for the existing Linux/Windows CI
matrix, and `bun.lock` records the refreshed dependency graph.

## One formatter, separate linting

`bun run format` now invokes the built-in `bun fmt`. Configuration lives in
`bunfig.toml`: tabs, an 80-column print width, and LF line endings. The
formatter covers source, tests, scripts, Markdown, HTML, YAML, JSON, and TOML.
Git-ignored practice, coverage, and local data are skipped automatically;
editor settings and generated Drizzle snapshots are explicitly ignored.

Biome still checks lint rules and import organization. Its formatter is
disabled so the two tools agree about which one owns whitespace. The initial
formatting migration changes existing files to establish a clean baseline.

```bash
bun run format                # Write formatting changes
bun run format:check          # Check without writing; used in CI
bun run lint                  # Biome lint and import checks
bun run fix                   # Biome fixes, followed by Bun formatting
bun fmt --changed=origin/main # Format changes relative to main
```

`bun fmt --staged` is available for an optional local pre-commit hook; it
formats and re-stages staged files. No hook is installed by this upgrade.

## Runtime lessons

The [Bun runtime guide](../src/node-concepts/bun-runtime/BUN_RUNTIME_GUIDE.md)
and executable tests cover the expanded `Bun.Glob` syntax: extglobs, numeric
brace ranges, and literal matching behavior. The SQLite lesson demonstrates
JavaScript-defined SQL functions and aggregates using an in-memory database.
These examples run without external database services.

The existing `bun --check` type gate benefits from 1.4.4's checker improvements.
The explicit flag remains necessary because the repository's `check` script
shadows the `bun check` command. The standalone TypeScript compiler remains a
separate compatibility check.

## CI and verification

CI runs the Bun format check before Biome lint, both type checkers, local
documentation checks, practice catalog checks, and tests with coverage on
Linux and Windows. Linux also validates every generated practice exercise and
audits dependencies. Frozen installs remain mandatory. The install step sets
`BUN_CONFIG_HTTP_RETRY_BACKOFF=250` to use the new exponential retry behavior
with a longer initial delay during temporary registry failures.

```bash
bun install --frozen-lockfile
bun run check
bun run practice:validate
bun audit
```

Local verification completed October 25, 2026 on Windows with Bun 1.4.4:
`bun run check` passed all 2,620 tests across 64 files, both type checkers,
formatting, lint, documentation links, and the practice catalog audit. Coverage
was 96.15% of functions and 96.39% of lines. All 306 generated practice targets
validated, frozen installation succeeded, and `bun audit` found no
vulnerabilities across 359 audited packages. The pull request runs the same
checks on Linux and Windows, with full practice validation and auditing on Linux.

The upgrade also repairs existing links to missing October upgrade notes by
pointing readers to the current upgrade and the relevant practice/lab guides.
