    Try three experiments

    1. Retry a write. Publish, then retry. Commits stay the same; safe retries increase.
    2. Lose the connection. Disconnect this tab. Publish in another, then reconnect here.
    3. Restart the server. Keep both tabs open. Stop and restart the lab; committed history survives.

    The invariant to remember

    Persistence owns the truth. WebSockets carry notifications. A stable event ID prevents duplicate writes; an ordered cursor recovers missed delivery. These are separate guarantees.
